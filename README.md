# PagPouco — Vercel

Projeto Next.js responsivo para publicação na Vercel.

## Rodar
npm install
npm run dev

## Publicar
1. Envie este projeto para um repositório GitHub.
2. Na Vercel, importe o repositório.
3. Framework: Next.js (detecção automática).
4. Build: `npm run build`.
5. Adicione as variáveis de `.env.example` apenas quando configurar o backend/gateway.

A tela de checkout deste starter é demonstrativa. Para pagamentos reais, implemente backend, banco, autenticação, criação de pagamento e webhook do gateway antes de aceitar valores reais.
